# Jupiter paper trading vault

- [[Research]] records the evaluation protocol, data workflow, and later hypotheses.
- [[Decisions]] records durable design choices, costs, and requirements for changing execution mode.

Keep assignments and progress in GitHub Issues and commands in the repository README. Open this folder inside your own clone and share Markdown changes through Git. When an experiment runs, give it one compact note with the experiment ID, inputs, method and evidence. Keep machine settings, credentials, extracts and runtime ledgers outside shared notes.
